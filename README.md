# 냉장고 한 끼

냉장고에 있는 식재료와 소비 권장일을 관리하고, 등록한 재료로 만들 수 있는 레시피를 제안하는 React Native 앱 프로젝트입니다.

## 개발 환경

- React Native + Expo + TypeScript
- iOS와 Android에서 같은 코드 사용
- 사진 촬영과 앨범 선택은 Expo ImagePicker 사용

## 시작하기

1. Node.js LTS와 npm을 설치합니다.
2. 프로젝트 폴더에서 `npm install`을 실행합니다.
3. `npx expo start`를 실행합니다.
4. 휴대폰에 Expo Go를 설치한 뒤 터미널의 QR 코드를 스캔합니다.

## 현재 구현 범위

- 홈: 냉장고 요약, 먼저 소비할 재료, 재료 기반 레시피
- 내 냉장고: 사진 선택/촬영, 식재료 직접 등록, 구매일과 소비 권장일 입력
- 레시피: 보유 재료와 일치하는 예시 레시피 추천
- 날짜 기반으로 남은 기간을 계산해 상태 표시

사진에서 식재료를 자동 인식하는 기능과 실제 레시피 데이터 연결은 아직 포함하지 않은 다음 개발 단계입니다. 사진만으로 식품이 실제로 상했는지 판정하지 않으며, 입력 날짜 기준으로 안내합니다. 현재 재료 목록은 앱 실행 중 메모리에만 저장됩니다.
